# 桌面页面与操作流程草案

## 状态与依据

本文件的基础布局已获用户确认并已有开发版本。已确认功能边界以[首版范围](v1-scope.md)为准；实际验证边界见[开发指南](../getting-started/development.md)。

已确认同时提供全局搜索与流程导航、完整窗口与置顶悬浮窗口。下面记录页面组织和操作顺序；托盘与独立搜索栏的默认快捷键见下文。

## 页面组织

| 页面           | 业务员操作                                                       | 管理员操作                                       |
| -------------- | ---------------------------------------------------------------- | ------------------------------------------------ |
| 销售工作台     | 搜索、选择语言、流程导航、填写变量、复制、查看关联素材           | 使用已发布资料进行同样操作                       |
| 话术与流程编辑 | 编辑个人分支、添加话术与连接、查看管理员版本、明确恢复管理员版本 | 编辑主库草稿、维护语言、导入 Excel、调整流程     |
| 知识库         | 搜索、预览、定位 Excel 结果、导出素材；查看失效引用              | 导入文件、维护分类标签和备注、编辑文字、删除素材 |
| 发布与同步     | 查看当前版本、更新进度、重试失败任务、导入备用资料包             | 查看草稿改动与发布状态、发布版本、导出资料包     |
| 工作组与备份   | 查看连接和本地资料状态                                           | 查看工作组状态、创建备份与恢复                   |

备份保留策略和业务员个人分支备份入口仍待细化，不将管理员主库备份当作已经包含所有业务员的个人内容。

## 完整工作台布局

建议采用顶部全局搜索、左侧导航、中央话术内容、右侧关联素材的布局。空间不足时，关联素材切换为可展开区域。

```text
┌────────────────────────────────────────────────────────────┐
│ KnowToSay   [搜索话术、素材、Excel…]    发送语言 ▾   同步状态 │
├───────────┬───────────────────────────────┬────────────────┤
│ 工作台    │ 流程入口 / 当前流程路径        │ 关联素材       │
│ 话术流程  │                               │                │
│ 知识库    │ 当前问题、回复与版本标记      │ 图片 / 视频    │
│ 发布同步  │ 变量填写 → 完整回复预览       │ Excel / 文字   │
│ 工作组    │                               │                │
│           │ [复制回复] [上一步]           │ 预览 / 导出    │
│           │ 客户回答：[选项一] [选项二]   │                │
├───────────┴───────────────────────────────┴────────────────┤
│ 当前资料版本 / 离线或同步进度               [切换悬浮窗口] │
└────────────────────────────────────────────────────────────┘
```

管理员的发布操作与业务员的同步状态需要不同文案；“发布同步”是导航示意，业务员不能看到可执行的发布主库动作。

## 知识库分类

管理员在知识库顶部点击“新建分类”，填写名称后创建。系统去除首尾空白，拒绝空名称、换行和重名；“未分类”为内置分类。创建成功后自动切换到该分类，即使暂时没有素材也保留筛选入口。素材编辑可选择或输入分类，当前分类下新建文字和导入文件会沿用分类。业务员只能查看和筛选管理员已发布的分类。

空分类通过独立数据库记录保存，旧版素材中的分类在升级迁移时自动收集。新增分类会标记为未发布草稿；局域网同步、离线资料包与管理员备份恢复均包含分类。

## 搜索与流程协作

1. 初次进入工作台，同时提供搜索框与流程入口列表。
2. 输入关键词后展示话术、素材、Excel 命中结果，标明结果类型和来源。
   话术结果同时显示“中文”和“한국어”两段回复，不随发送语言切换隐藏其中一种。缺失语言显示对应提示；发送语言只决定复制的内容。
3. 点击话术结果查看对应回复，结果标注“流程话术”或“快捷话术”；不因只输入关键词就改变当前流程位置或复制内容。工作台与编辑页在内容上方共用两级导航：先选择流程话术或快捷话术，再选择流程或分类标签；布局、选中样式与切换方式一致，悬浮窗同样提供切换。快捷问答不显示下一步分支。
4. 点击素材结果预览并导出；点击 Excel 结果定位到工作表和行。
5. 选择流程后显示当前步骤、路径与下一步选项；业务员选择客户回答后前进，可以返回上一步。
6. 选择目标语言、填写变量、预览后复制。缺失语言不能静默复制另一语言；必填变量缺失时应指出具体字段。
7. 对有个人修改的内容明确显示“个人版”，并提供“查看管理员版本”和“恢复管理员版本”。恢复是显式操作，不由同步触发。

流程导航不展示需要客户档案的表单。目标语言可切换；初始语种与内部辅助译文的呈现方式尚未最终确定。

话术旁的“查看完整流程”在工作台展开流程图。图中包含当前话术通过连线相连的全部步骤，同时遍历上游和下游，保留其他回答分支与汇合；其他独立流程和快捷话术不混入。当前节点高亮，点击节点直接查看回复，滚轮缩放、拖动空白处平移。此处不修改节点布局或连接，收起图表后继续当前步骤。

## 精简悬浮窗口

建议悬浮窗口以单列呈现，保持可拖动、可置顶；窗口较小时通过滚动和展开显示较长内容。

```text
┌──────────────────────────────┐
│ KnowToSay   置顶   完整窗口   │
│ [搜索…]          发送语言 ▾  │
├──────────────────────────────┤
│ 当前流程 / 返回              │
│ 当前问题      个人版 / 官方版 │
│ 变量填写                     │
│ 回复预览                     │
│ [复制回复]                   │
│ 下一步：[选项一] [选项二]    │
│ 关联素材 ▾                   │
├──────────────────────────────┤
│ 离线可用 / 同步状态          │
└──────────────────────────────┘
```

切换窗口保留当前临时步骤、目标语言和已填写变量；不自动发送内容，也不要求用户先切回完整窗口才能完成必需变量填写。复杂流程编辑在完整窗口完成。

## 话术与流程编辑

完整窗口内提供“流程话术”和“快捷话术”两个标签。流程话术使用流程画布与选中步骤属性面板：画布维护分支、汇合和跳转；快捷话术使用可搜索的独立问答列表。两类共用属性编辑，支持题目、客户问题、多语言回复、变量和素材引用。快捷话术的“新建分类”与“新建流程”复用标签组件；允许先建空分类，再创建话术。新话术默认归入当前分类，编辑时可移至已有分类。切换分类保留全部未保存草稿，分类标签支持与流程相同的拖动、键盘和排序弹窗，本机顺序在两个页面及悬浮窗保持一致。

流程画布从左向右展示步骤，支持以下操作：

1. 拖动节点调整位置；“自动排列”重新整理全部流程节点。
2. 从节点右侧圆点拉箭头到另一节点左侧圆点，填写“分支条件 / 客户回答”并确认。
3. 将箭头拉到空白处，填写条件和子话术题目，创建已连接的新步骤；随后在右侧维护回复、变量和素材。
4. 点击连线修改条件或删除分支。多个条件可以连接同一个步骤，也可以形成汇合或循环跳转。
5. 图表和属性面板共用编辑草稿。节点切换和两类话术标签切换保留未保存内容；“保存流程”和“保存话术”都会统一保存所有改动，离开编辑页前提示确认放弃。

批量保存接口 `PUT /api/v1/scripts` 接收 `SaveScripts.nodes`，只包含实际改动的话术。校验重复标识、类型和流程目标后，在同一个 SQLite 事务中保存新节点、布局及源节点分支；任何写入失败均回滚。管理员写入主库草稿，业务员写入个人分支并保留官方依赖，个人节点布局和连接同样受同步保护。

快捷话术不提供流程入口或分支配置，流程连接只能选择流程话术。通过“话术类型”显式转换已有话术；含分支或被其他步骤引用的流程话术需先解除连接才能转为快捷话术，不能因切换类型静默删除连接。没有分支的流程末步仍属于流程话术。

管理员保存为主库草稿；业务员保存到个人分支。保存目标应在界面持续可见，避免用户误解为在改管理员主库。个人新增话术与个人连接也应有清晰标记。

Excel 导入先预览字段映射与错误，确认后写入。后续需用实际样表确定重复导入和多语言列的识别规则，不凭行号判定既有话术。

## 发布、同步与素材移除

管理员在发布页查看本次新增、修改、移除的项目，确认发布后业务员才可获取。业务员可以查看同步进度，离线时继续使用当前完整版本，失败后重试。

当已同步版本包含素材移除时，个人话术保留正文与流程，关联区域显示“素材已移除”，并提供重新选择素材的入口；不再提供该素材的预览和导出。个人引用不会阻止管理员移除公共素材。

管理员删除的官方话术与个人流程结构发生冲突时，保留个人编辑的具体呈现与处理仍待细化；不能通过自动覆盖个人流程来消除冲突。

## 托盘与独立搜索栏

工作台最小化或关闭后隐藏到托盘并保留当前流程状态。托盘提供打开工作台、打开搜索及明确退出。

全局快捷键打开独立全库搜索，默认 Ctrl+Alt+Space。鼠标触碰指定屏幕边缘并达到停留时间后打开“快捷话术回复表”，默认右边缘停留 400ms。其他三边可以在设置中开启，停留时间可设为 200–2000ms。边缘检测只在工作台收起时启用，并避开拖拽与其他全屏应用。

回复表直接展示独立快捷话术的客户问题及中韩双语回复，支持筛选、切换发送语言与一键复制，每次加载 50 条并可继续显示。有必填变量时先填写预览；缺少发送语言时提示选择其他语言。搜索结果及话术详情也保留双语参考和独立的复制预览。回复表与全库搜索可在窗口内切换。全局快捷键在回复表打开时切换到全库搜索，再次按下则收起全库搜索。

独立搜索按话术、素材分类展示结果，可用方向键和 Enter 查看；话术支持目标语言、变量预览与复制，以及打开主工作台的对应步骤。Esc 收起。复制成功默认收起，并尝试返回唤出前的 Windows 前台窗口；不自动粘贴或发送。

原生独立窗口使用根路由 `/?quickSearch=1`，避免将 `index.html` 当作 SvelteKit 页面路由造成 404。生产静态构建的两种面板及复制操作纳入浏览器回归测试。

快捷键注册冲突必须显示可恢复的设置提示，不能宣称已注册成功。真实托盘、跨显示器边缘检测、快捷键占用和焦点恢复需在 Windows 验证。

## 首次启动与工作组

- 首次启动提供“创建工作组”和“加入工作组”。创建并初始化成功的电脑成为管理员。
- 加入时发现已有管理员，再取得资料；无法发现时提示检查连接，不自动创建新管理员。
- 已加入电脑再次启动直接进入本地工作台，同步状态独立显示；管理员离线不阻断已有资料的使用。

## 视觉与目标平台验证

[DESIGN](../../DESIGN.md) 是前端视觉实现的强制依据，后续页面必须复用 `apps/web/src/app.css` 的设计变量和现有组件样式。原始 DESIGN 文档保持不变。

| DESIGN 要求                | 桌面端对应实现                                                                                       |
| -------------------------- | ---------------------------------------------------------------------------------------------------- |
| 单一 Action Blue           | 操作与链接 `#0066cc`，焦点 `#0071e3`；`#2997ff` 仅用于深色背景                                       |
| 白色、Parchment 与深色画布 | 主内容白色、工作区 `#f5f5f7`，首次启动深浅分区；全局导航纯黑 44px                                    |
| 字体与层级                 | SF Pro 优先；Windows 内置打包 Inter 作为西文替代，中文和韩文使用系统字体；不依赖在线字体服务         |
| 正文与标题                 | 正文 17px / 400 / 1.47；说明标签 14px，状态栏 12px；主标题 40px / 600，首次启动 56px，随窗口宽度调整 |
| 按钮、搜索框               | 蓝色主按钮与蓝色描边次按钮为胶囊形；搜索输入 44px 高；按下缩放 0.95；键盘焦点为 2px 蓝色轮廓         |
| 卡片与深度                 | 工具卡片 18px、紧凑控件 8px 圆角，使用细分隔线；界面组件无装饰阴影、无渐变                           |
| 顶部工具区                 | 主导航下方 52px Parchment 半透明工具栏；搜索与发送语言保持可访问                                     |
| 布局与可访问性             | 内容最大宽度 1440px；小窗口改为单列与滚动，按钮点击区域至少 44px，遵循减少动画设置                   |

营销页中的产品摄影、购买按钮和大图分区不适用于销售工作台；桌面端保留已确认的左侧导航、流程与素材布局，用同一套视觉规范呈现内容。独立搜索栏也复用色彩、字体、胶囊搜索框与焦点规范。

原生置顶、窗口切换、剪贴板、文件定位、中文与韩文等文字输入，以及与 LDCLOUD 并排操作，都需要在真实 Windows 环境验证。本文线框仅用于讨论，不代表目标平台已经验证。
