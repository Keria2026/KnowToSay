# 桌面页面与操作流程

## 状态与依据

本文说明当前开发版本的页面与交互。产品边界见[首版范围](v1-scope.md)，术语见[领域术语](domain-glossary.md)，运行、自动检查和目标平台验收见[开发指南](../getting-started/development.md)。实现与自动验证不代表已经通过 Windows 真机验收。

## 页面组织

| 页面       | 业务员操作                                             | 管理员操作                                                   |
| ---------- | ------------------------------------------------------ | ------------------------------------------------------------ |
| 销售工作台 | 流程或快捷话术导航、填写变量、复制、搜索、查看关联素材 | 使用主库草稿进行同样操作                                     |
| 话术与流程 | 编辑个人话术及连接、查看管理员回复、明确恢复管理员版本 | 编辑主库草稿、维护流程和快捷分类、导入 Excel                 |
| 知识库     | 筛选、搜索、预览、定位 Excel 结果、导出素材            | 新建分类、导入、编辑和删除素材                               |
| 设置       | 工作组状态、连接与同步、资料包导入、个人备份、桌面行为 | 发布、资料包导出、管理员备份恢复、跨工作组备份导入、桌面行为 |

发布与同步是设置页中按角色显示的内容，不是独立导航页。工作组身份和备份也在设置中；业务员没有发布主库的操作。

## 窗口布局与导航

完整窗口使用左侧品牌与四个页面入口、顶部搜索工具栏、主内容区的布局。销售工作台的主内容包括话术类型与流程或分类标签、入口列表、当前话术及关联素材。顶部不再有独立黑色品牌条，侧栏不再放工作组卡片；工作组信息在设置页查看。

侧栏当前页使用浅蓝底、蓝色 600 字重和 `aria-current="page"`，其他入口使用浅灰文字。搜索结果打开时不把某个导航页标成当前结果页。

置顶悬浮窗是只读销售工具，不包含新建、编辑、分类管理、发布、备份与设置入口。顶部保留搜索、范围选择、发送语言和“完整窗口”按钮；内容只分为流程、快捷话术、知识库三项。

- 流程：选择已有流程，查看当前题目、精简中文参考、复制内容和必要变量；可复制、前进分支、返回上一步及取用关联素材。
- 快捷话术：选择已有分类，回复卡片直接复制；详情与必填变量按需打开。
- 知识库：按类型和分类选择素材，文字直接复制，文件导出，详情预览按需打开。
- 复制仍受发送语言与变量校验约束，不显示编辑表单。查找或取用内容不会丢弃完整窗口中尚未保存的草稿。
- 完整页面组件保留在隐藏且不可交互的容器中，悬浮工具复用共享业务状态、复制卡片和预览组件；切回完整模式恢复原来的编辑页面、窗口尺寸与位置。窄窗内容内部滚动，不把完整管理页面缩小塞入悬浮窗。

## 流程与快捷话术导航

工作台和编辑页共用两级导航：先选“流程话术”或“快捷话术”，再选流程名称或快捷分类标签。悬浮窗仅使用已有流程与分类的选择器，不提供标签管理。

- 流程具有独立名称和稳定标识，可新建、重命名；空流程也保存并随发布、同步和备份保留。步骤按 `flowId` 归属于一条流程，不使用分类。
- 快捷分类可先创建为空，再添加话术。管理员管理主库分类，业务员管理自己的个人分类；官方分类只读。“未分类”不能重命名或删除。
- 重命名快捷分类会同步更新其中话术；删除分类把话术移入“未分类”。已有回复与未保存编辑保留。
- 流程和快捷分类均支持标签拖动、Alt + 左右方向键及排序对话框。顺序按工作组保存在本机，在工作台、编辑页和悬浮窗共用；不发布或同步给其他电脑。
- 切换类型、流程或分类保留所有未保存话术修改。新建话术归入当前流程或快捷分类。

## 搜索、语言与发送

1. 搜索默认覆盖话术、知识库素材与 Excel 单元格，可限定流程话术、快捷话术或知识库，并进一步选择某条流程或分类。完整窗口、悬浮工具和独立搜索复用范围选择逻辑；系统快捷键唤出时回到全局搜索。输入关键词本身不发送或复制。
2. 搜索结果、独立搜索栏和快捷回复表同时展示中文与韩语参考，缺失版本明确提示。发送语言决定复制哪一种回复，不自动回退到另一语言；初始发送语言为韩语，可切换。
3. 结果卡片直接提供复制操作；点击详情才展开完整内容。缺少必填变量时先填写、预览，缺少发送语言时禁止复制。文字素材直接复制，文件素材直接导出。
4. 工作台选择入口或分支后展示当前步骤；点击下一步会推进临时导航，可返回上一步。不建立客户档案，也不按客户保存进度。
5. 复制前校验变量；必填或未声明的占位符未补齐时不复制，明确声明的可选变量可以留空。预览已填写值后复制，客户端不自动向 KakaoTalk 发送。
6. 素材点击后预览或导出；Excel 搜索结果定位到工作表和行。导出或打开文件所在位置后，由使用者手动上传到 LDCLOUD 云机。
7. 个人话术优先展示，来源标记区分个人版本、管理员版本与保留的话术。编辑页可查看当前管理员回复；恢复管理员版本需明确确认，不由同步触发。

## 流程图查看与全屏

工作台“查看完整流程”展示当前流程的全部步骤，包括未连接步骤；其他流程与快捷话术不混入。当前话术高亮，点击图中步骤会切换工作台当前话术。画布支持缩放、平移与适应画布，不提供节点拖动或连线编辑。

工作台展开的流程图与编辑页画布均提供“全屏查看流程”。桌面使用原生窗口全屏，浏览器使用 Fullscreen API；全屏请求失败时明确提示，并保留窗口内全屏查看。

- 全屏画布显示当前流程，右侧悬浮竖向详情面板显示所选节点的问题、中韩回复、变量、发送语言、复制预览、下一步与关联素材名称。
- 点击节点或详情中的下一步，只改变全屏查看的选中节点，不隐式修改工作台当前步骤、布局、连线或编辑草稿。
- 工作台入口可选“在工作台继续此步骤”再切换当前话术；编辑入口可选“返回编辑此步骤”定位编辑器。编辑页的全屏查看读取包含未保存修改的当前记录。
- “退出全屏”、Esc 或 F11 返回原窗口。进入前已经处于原生全屏时，退出查看保留原全屏状态。
- 窄屏布局将详情放在画布下方，内容可独立滚动；正常桌面宽度保持右侧竖向面板。

## 话术与流程编辑

流程编辑器由当前流程画布与步骤属性面板组成；快捷话术使用按分类筛选、可搜索的问答列表。两种类型共用题目、问题、多语言回复、变量与素材引用编辑，语言使用可读名称。

类型在创建入口确定，编辑器不提供类型切换或入口复选框。空流程中首个新建节点自动作为入口，后续节点不是入口；已有入口标记保留。快捷话术不能作为流程分支目标，流程连接只能指向同一流程的步骤。

流程画布支持：

1. 拖动节点保存手动坐标；“自动排列”只重排当前流程。自动排布按分支顺序与子树空间分隔分支，汇合放在最长上游路径之后，循环保留返回箭头。
2. 从节点右侧新增连接点拉到目标节点，填写分支条件；拉到空白处则创建已连接子步骤。
3. 分支条件显示在来源步骤内部，每条分支使用独立连接点。点击连线或可编辑的分支条件修改、删除连接。
4. 在画布和右侧面板间切换节点、类型或标签，保留全部未保存修改。
5. “保存流程”与“保存话术”提交所有实际变化的话术，按同一 SQLite 事务保存；失败整体回滚并保留界面待保存内容。

管理员保存到主库草稿，业务员保存到个人分支。管理员工作台读取草稿，业务员只读取管理员已发布资料及自己的个人覆盖；“保存成功”不等于“已发布”。Excel 导入规则见开发指南，不用行号或标题推断话术身份。

## 知识库分类与素材

管理员可独立新建分类，无素材的空分类仍保留。名称去除首尾空白，不能空白、包含换行、重名或超过 80 字符。“未分类”为内置分类。当前分类下创建文字或导入文件沿用该分类，全部分类视图下归入未分类。

知识库分类与快捷分类互相独立。知识库分类和素材属于主库草稿，发布后才由业务员使用，空分类也随同步、资料包和管理员备份保留。

管理员删除素材并发布后，业务员成功同步才移除其可用入口。个人话术保留失效素材引用并提示“素材已移除”，可重新关联；不因个人引用继续提供已删除素材。草稿删除、离线或同步失败不能提前影响业务员当前已安装版本。

## 发布、同步与个人内容

管理员在设置查看草稿状态、发布和导出已发布资料包。业务员在设置查看版本、连接与同步进度，可重试同步或导入资料包。管理员关闭时，已加入的业务员继续使用本地资料。

个人话术默认覆盖同 ID 管理员话术；未修改话术跟随管理员发布。保存个人修改时保留其官方流程与步骤依赖，管理员后来删除这些步骤时，以“保留的话术”继续支持个人流程。仍存在的官方话术提供当前官方回复供参考；恢复管理员版本会清除相应个人覆盖，并清理不再需要的依赖。当前没有逐字段合并或可视化冲突解决器。

下载的新资料与素材全部校验通过后才切换；续传、空间检查和失败保留旧版本的规则见开发指南。

## 备份、恢复与跨组导入

| 操作               | 内容与边界                                                                                                                               |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------- |
| 管理员备份         | 保存本工作组身份、主库草稿、已发布资料及所需素材，不收集其他电脑的个人分支                                                               |
| 恢复同一工作组     | 校验备份后恢复该工作组；已有工作组只接受同组恢复，恢复后产生新的发布版本；旧管理员需先退出                                               |
| 导入其他工作组备份 | 将备份的草稿资料追加到当前管理员主库，重新分配标识并重建流程、分支和素材引用，保留排版；当前身份、已有资料和发布版本不变，检查后另行发布 |
| 个人备份恢复       | 仅针对当前业务员所属工作组，替换个人话术、流程、快捷分类和必要依赖；不替换管理员资料或知识库                                             |
| 资料包导入         | 安装管理员的已发布版本，遵循同步校验及个人修改保护；不能当作管理员备份恢复                                                               |

导入其他工作组备份与恢复本工作组是不同操作，界面分别提供入口；同名导入流程自动加后缀。

## 表格预览与自适应

Excel 按实际行列显示，列名为 A、B、…、AA，保留原始行号和空单元格；新导入文件同时保留非 A 列起始位置。支持切换工作表、每页 150 行、横向滚动和搜索命中标记。点击单元格复制该内容，复制行使用制表符分隔；每次显示最多 40 列，超宽表格可切换列组。按文件名搜索后打开表格不强制用文件名过滤单元格。

组件随窗口宽高重排，搜索工具栏可换行、结果卡片在窄窗下纵向排列、编辑器在窄窗下置于画布下方；表格仅在内部滚动。搜索窗口可手动调整尺寸，首次展开结果时保持用户宽度；新打开窗口限制在显示器可用尺寸内。浏览器缩放与原生多屏 DPI 的实测边界见开发指南。

## 托盘与独立搜索栏

Windows 工作台最小化或关闭后常驻托盘。托盘可打开工作台、打开搜索或明确退出程序。

- 默认 Ctrl + Alt + Space 打开独立全库搜索，可修改或关闭。快捷键在回复表打开时切换为全库搜索，再次按下收起搜索。
- 默认右边缘停留 400ms 打开快捷话术回复表；四边可单独配置，停留时间 200–2000ms。仅在工作台收起时启用，拖拽或其他全屏应用中暂停。
- 回复表显示独立快捷话术的客户问题与中韩双语回复，支持筛选、发送语言和复制，每次加载 50 条并可继续显示。全库搜索与回复表在同一独立窗口内切换。
- Esc 收起；复制成功默认收起并尝试恢复之前 Windows 前台窗口，不自动粘贴。快捷键注册冲突在设置显示，不能把注册失败当成功。
- 原生独立窗口使用根路由 `/?quickSearch=1`，生产静态路由与浏览器回归共用该入口。

## 首次启动

首次启动明确选择创建工作组或加入工作组，也可按界面入口导入资料包或恢复备份。创建成功才建立管理员身份；加入时可自动发现或填写管理员局域网 IPv4 地址，首次加入需要管理员已发布且在线。发现失败不自动创建管理员，已加入电脑再次启动不依赖管理员在线。

## 视觉、品牌与验证边界

[DESIGN](../../DESIGN.md) 是视觉规范；桌面 UI 使用 `apps/web/src/app.css` 的统一变量，不照搬营销页摄影、购买按钮或黑色品牌条。

| 项目           | 桌面规则                                                                              |
| -------------- | ------------------------------------------------------------------------------------- |
| 颜色           | 单一蓝色交互信号，白色与 Parchment 画布；浅蓝当前导航、浅灰未选中导航                 |
| 字体           | SF Pro 优先，离线打包 Inter，中文和韩文使用系统字体；正文 17px / 400 / 1.47，强调 600 |
| 形状与深度     | 主按钮和搜索框为胶囊，工具卡片 18px、紧凑控件 8px；细分隔线，无装饰阴影或渐变         |
| 顶部与响应布局 | 搜索工具栏从内容顶部开始，完整窗口与窄悬浮窗共用导航；全屏画布使用整个屏幕            |
| 品牌           | 应用内 Logo 统一引用 `static/icon.svg`，桌面 PNG/ICO 与安装器图标从同一设计生成       |
| 升级图标       | 安装器携带独立图标资源，刷新已有桌面与开始菜单快捷方式，并通知 Explorer 更新图标缓存  |

浏览器自动回归覆盖全屏、节点详情和退出后的状态保留。Windows 安装升级后的图标刷新、原生全屏和窗口恢复、托盘、多屏 DPI、边缘检测及真实 LDCLOUD / KakaoTalk 操作仍需目标平台验收。

备份设置使用“用备份替换当前工作组”与“追加导入其他工作组资料”两个明确名称：前者替换当前草稿和已发布资料并产生新的发布版本；后者保留当前资料、身份和已发布版本，只追加来源草稿，检查后再发布。
