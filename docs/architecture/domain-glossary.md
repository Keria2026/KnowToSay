# 领域术语

| 术语 | 定义 |
| --- | --- |
| 工作组 | 同一局域网内由一个管理员统一维护和发布资料的销售团队。 |
| 管理员 | 首台明确创建并完成工作组初始化的电脑所持有的管理身份，负责主库维护、发布和备份恢复。 |
| 业务员 | 加入既有工作组、使用统一知识库并可编辑个人话术分支的成员。首版没有在线账号。 |
| 主库 | 管理员维护的话术、流程和知识库资料的权威来源。业务员编辑不会修改主库。 |
| 草稿 | 管理员尚未发布的编辑内容，业务员不能通过同步取得这些内容。 |
| 发布版本 | 管理员明确发布的一组一致的话术、流程和素材引用，供业务员同步使用。 |
| 话术 | 包含题目、问题和多语言回复的销售沟通内容，可定义复制前填写的变量并引用素材。 |
| 话术流程 | 由话术步骤及选择关系组成的沟通路径，支持分支、汇合和跳转。 |
| 个人分支 | 业务员独立编辑的话术及流程，支持新增内容和调整连接；不回传主库，不被管理员更新覆盖。 |
| 知识库素材 | 由管理员统一维护、供业务员查找和发送的文字、图片、视频或 Excel 等资料。 |
| 变量 | 话术中需要在复制前填写的内容位置，例如客户姓名、产品名称、价格。 |
| 资料包 | 管理员导出、业务员导入的一组可离线分发的资料，用于局域网同步之外的备用交付。 |

管理身份用于确定操作职责，不等同于经过登录或授权验证的安全身份。
