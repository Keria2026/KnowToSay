# 领域术语

| 术语             | 定义                                                                                                                         |
| ---------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| 工作组           | 由一个管理员统一维护与发布资料、业务员各自离线使用的一组客户端。                                                             |
| 管理员           | 明确创建并初始化工作组的客户端角色，负责主库、发布和备份恢复；不会因其他电脑离线而自动转移。                                 |
| 业务员           | 加入一个工作组，使用已发布资料，并可独立维护个人话术和流程的客户端角色。                                                     |
| 主库             | 管理员维护的话术、流程、分类和知识库的权威资料。业务员个人修改不回写主库。                                                   |
| 未保存编辑       | 当前编辑器中尚未提交到本地持久存储的修改；切换节点、标签或窗口模式时保留，离开编辑页需确认放弃。                             |
| 主库草稿         | 管理员已保存、可继续编辑但尚未发布的主库资料；管理员工作台读取草稿，业务员无法通过同步取得。                                 |
| 发布版本         | 管理员明确发布的一组一致的话术、流程、分类与素材引用；业务员校验全部资料后整体切换到该版本。                                 |
| 话术             | 包含题目、客户问题、多语言回复，可关联变量和知识库素材的沟通内容；创建时确定为流程话术或快捷话术。                           |
| 话术流程         | 具有稳定标识与独立名称的一张沟通流程图，可以为空；以流程标签选择，不以分类区分。                                             |
| 流程步骤         | 归属于一条流程的话术，可设置指向同一流程其他步骤的分支；没有分支的末步仍属于流程话术。                                       |
| 流程入口         | 用于开始导航的步骤；空流程中首个新建步骤自动成为入口，已有入口标记保留。                                                     |
| 流程分支         | 来源步骤上的客户回答或条件，及其指向的目标步骤；允许分叉、汇合和回跳。                                                       |
| 快捷话术         | 独立的一对一问答，不属于流程，没有流程入口和分支，也不能成为流程分支的目标。                                                 |
| 快捷话术分类     | 组织快捷问答的独立分组，可为空；管理员管理主库分类，业务员可管理个人分类。“未分类”为不可删除的默认分类。                     |
| 个人分支         | 业务员本地保存的话术修改、个人新建步骤或流程及其连接；优先于同 ID 管理员话术，不回传或影响其他业务员。不同于单个“流程分支”。 |
| 保留的话术       | 管理员已删除但仍被个人内容依赖的官方步骤副本，用于保留个人流程上下文；不代表其失效素材仍可使用。                             |
| 管理员版本       | 业务员当前已安装发布版本中的官方话术；个人修改存在时可供参考或明确恢复。                                                     |
| 恢复管理员版本   | 明确放弃某条话术的个人覆盖并回到当前官方内容，不是同步时的隐式覆盖。                                                         |
| 知识库素材       | 管理员统一维护的文字、图片、视频或 Excel 等内容；业务员只使用已发布素材。                                                    |
| 知识库文件夹     | 以稳定 ID 和上级文件夹组织资料，支持嵌套、改名、移动，空文件夹随发布和备份保存；与快捷话术分类分别管理。 |
| 案例             | 一份可复制的文案及有顺序的多张图片组成的知识库素材；每张图片可单独预览、复制及导出。 |
| 变量             | 复制回复前需要填写或检查的占位内容，如客户姓名、产品名称、价格。                                                             |
| 发送语言         | 本次复制的回复语言；中韩参考文本同时展示不意味着两种语言一起复制。                                                           |
| 全屏流程查看     | 查看所选流程全部步骤的只读模式，点击节点显示详情；不会隐式切换工作台步骤或修改编辑草稿。                                     |
| 精简悬浮窗口     | 完整工作台的窄窗布局，可置顶并访问同样四个页面；不是独立资料库。                                                             |
| 独立搜索栏       | 不打断工作台当前流程的统一搜索入口，通过范围选择全局、流程话术、快捷话术或知识库。                                                       |
| 本机标签顺序     | 当前电脑按工作组保存的流程或快捷分类显示偏好，不属于主库发布资料。                                                           |
| 资产 | 通过统一入口导出的资料。管理员包含主库、发布资料和知识库；业务员仅包含个人分支。导入按当前角色处理，工作组身份不随管理员资产迁移。 |
| 旧资料包 | `manifest.json` 与素材文件构成的历史发布格式，统一资产入口接受管理员导入为主库，或同组业务员离线更新。 |

管理身份用于本地操作职责划分，不等同于在线账号、经过认证的用户权限或资料防复制机制。实现细节与文件格式见[开发指南](../getting-started/development.md)，交互见[桌面页面与操作流程](desktop-interactions.md)。
