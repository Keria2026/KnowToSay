# 第一版范围与验收场景

## 目标与状态

为多语言销售提供可离线运行的 Windows 10+ Tauri 桌面客户端，用于沿沟通流程选择话术、填写变量、复制回复，以及查找和导出知识库素材。

本文记录已确认范围。仓库已有开发版本及自动测试；实现与目标平台验证边界见[开发指南](../getting-started/development.md)。

## 工作组与角色

- 一个局域网按一个工作组使用，只有一个管理员提供资料同步。每名业务员只属于一个管理员。
- 通过首次明确选择“创建工作组”并完成初始化建立管理员身份，不以安装时间戳或一次网络探测失败来选举管理员。
- 后续电脑加入已有工作组成为业务员。首次加入需要管理员在线；已经加入的电脑可继续离线使用。
- 管理员身份持久保存，不因客户端退出或网络不可达自动转移。新电脑找不到管理员时，不自动成为新管理员。
- 首版不登录、不做在线授权。管理模式和业务员模式划分操作职责，不宣称提供已认证的账号权限或资料防复制保护。

## 话术与流程

- 预估约 2,000 条话术。支持题目、问题、多个语言版本的回复。
- 管理员人工录入各语言版本；支持从现有 Excel 话术表批量导入。
- 支持分支、汇合、跳转及共同话术复用；使用时可沿流程选择、返回和复制。
- 话术支持客户姓名、产品名、价格等变量，复制前填写、预览；必填变量缺失时提示。
- 话术步骤可以引用知识库中的图片、视频、表格等素材。
- 不建立客户档案，不按客户保存流程进度。

## 业务员个人分支

- 业务员可以修改题目、问题、多语言回复、变量，新增个人话术并调整流程连接与分支。
- 个人修改只保存在本地，不回传管理员，不影响其他业务员。
- 管理员发布版本持续同步。业务员修改过的内容保持个人版本，未修改内容跟随管理员更新；最新管理员版本仍可供查看。
- 默认使用个人版本，支持明确放弃个人修改并恢复管理员版本。此操作不能作为同步时的隐式行为。
- 话术、流程及引用需要稳定标识，不能按标题、列表位置或 Excel 行号猜测同一项内容。
- 同步不得整体覆盖业务员数据库，亦不得静默丢弃个人新增话术或流程连接。
- 知识库由管理员统一管理，业务员可引用和使用，不能将知识库修改作为个人分支回传或发布。

流程结构发生冲突时如何展示差异、个人分支引用的管理员话术被删除后如何保留上下文，仍需在流程设计中细化；必须保证个人修改不丢失，且不能将失效引用静默连接到其他话术。

## 知识库与搜索

- 预估素材总量 20–30GB，支持文字、图片、视频和 Excel。
- 支持分类、标签、备注、查找和预览。
- 可搜索标题、分类、标签、备注、文字正文及 Excel 单元格；Excel 结果能定位到工作表和行。
- 第一版不做图片 OCR 或视频语音转写。
- 素材文件按需读取和预览，不要求将全库载入内存。
- 导入的素材在本地保存，源 Excel 或源素材移走后不能导致已入库资料失效。
- 管理员删除素材并发布后，业务员成功同步该版本时移除素材的可用入口。引用它的个人话术保留，关联处提示“素材已移除”，允许重新选择素材；不因个人引用继续提供旧素材。
- 管理员草稿中的删除不提前影响业务员；离线电脑在成功同步之前继续使用当前已安装版本。更新失败不能提前应用删除。历史回滚或备份中的文件不作为当前素材对业务员开放。

## 发布、同步与恢复

- 管理员编辑期间为草稿，明确点击发布后才向业务员提供更新。
- 管理员客户端运行时提供同步；业务员自动获取已发布更新，断线后重新连接时补齐。
- 首次全量获取，后续增量同步；大文件传输支持断点续传。
- 同步期间原版本继续可用。新版本需要完整性检查和空间检查，更新失败保留旧版本，不能形成半新半旧的可用发布版本。
- 素材与引用需一起达到可用状态，不能先切换到引用尚未传完素材的新版本。
- 个人话术分支不因更新、重试、断网、重启而丢失。
- 管理员具备备份和恢复功能，备份覆盖资料、素材及恢复工作组所必需的状态。
- 保留资料包导入导出，作为备用分发方式；仍需遵循同样的完整性与个人修改保护要求。

## 实际发送链路

业务员在 Windows 客户端选择文字或素材。文字复制后在实际 LDCLOUD / KakaoTalk 环境粘贴；素材通过打开所在位置或导出选中文件，手动上传到 LDCLOUD 云机，再在云机内的 KakaoTalk 选择发送。

不将桌面文件复制等同于已向云机传输；文本剪贴板能否跨云机使用需要实际验证。首版不自动上传云机，不自动向客户发送消息。

## 工作台与窗口

- 业务员同时频繁使用全局搜索和流程导航，两个入口均为主操作，不将其中一个藏入管理页面。
- 全局搜索覆盖话术、知识库素材和 Excel 内容。流程导航提供当前步骤、可选分支、返回及关联素材。
- 提供完整窗口和精简悬浮窗口。完整窗口承担资料管理、个人话术编辑和流程编辑；悬浮窗口可置顶，方便与 LDCLOUD 并排使用。
- 悬浮窗口保留搜索、当前话术、目标语言、变量填写、分支选择、返回和复制，并提供关联素材入口。
- 两种窗口使用同一份本地资料和个人分支。切换窗口不能丢失本次临时导航位置和已填写变量；这不等同于按客户保存进度。
- 悬浮窗口不扩展为 KakaoTalk 自动发送或云机文件自动传输工具。
- Windows 最小化或关闭工作台后常驻托盘，明确选择托盘“退出”才退出程序。通过托盘可以打开工作台或独立搜索栏。
- 全局快捷键与屏幕边缘均唤出独立搜索栏，不打断主工作台当前流程。默认快捷键为 Ctrl+Alt+Space，可修改或关闭；Esc 收起，复制成功后默认收起搜索栏。
- 默认右边缘停留 400ms 触发；上下左右四边可分别配置，停留时间可设置为 200–2000ms。边缘触发仅在主工作台已收起时启用，拖拽或其他全屏应用中暂停。
- 独立搜索栏可以搜索话术、素材和 Excel 单元格，填写必要变量并复制；也可明确打开主工作台中的对应话术。业务员个人版本优先。

## 技术与设计约束

采用 [已批准的桌面存储决策](../adr/0001-offline-desktop-storage.md)。工程规范见 [AGENTS](../../AGENTS.md)，视觉设计见 [DESIGN](../../DESIGN.md)。

视觉沿用单一蓝色强调色、统一排版与留白、克制的层级和组件规则。具体销售工作台与流程编辑布局仍需设计，不预设为营销网站的大幅图片布局。

## 必需验收场景

以下为必需验收目标。当前自动覆盖和仍待人工验证的场景见开发指南，不将全部目标视为已在真实 Windows 环境执行。

1. 两台电脑建立工作组，业务员同步已发布资料；管理员退出后，业务员仍可搜索、导航、填写变量并复制回复。
2. 管理员修改草稿，业务员看不到；发布后自动更新，未修改的官方话术及流程可以正常使用。
3. 业务员修改个人话术、新增步骤和连接；管理员更新相关官方内容后，个人内容和连接仍保留，且能够查看最新官方版本。
4. 中断大文件传输并重启客户端后续传；文件不重复写坏，空间不足或校验失败时不切换当前发布版本。
5. 搜索指定 Excel 单元格中的内容，结果对应正确工作表和行；原文件可定位和导出。
6. 管理员创建一致备份并在测试数据目录恢复，能重新识别工作组、读取话术流程及完整素材；恢复操作不能误生成第二个管理员。
7. 在真实 Windows、LDCLOUD 和 KakaoTalk 环境验证文本粘贴、素材导出及人工上传发送链路。
8. 在完整窗口和置顶悬浮窗口之间切换，搜索和流程均可使用；临时步骤与变量保持一致，切换不会重复创建或覆盖个人话术。
9. 管理员删除被个人话术引用的素材并发布；成功同步后素材不再可用，个人话术及流程保持，引用处明确提示失效；同步失败或草稿删除不提前移除当前可用素材。
10. Windows 最小化到托盘后，可通过配置的边缘或全局快捷键唤出独立搜索栏；Esc 收起，复制和打开流程不丢失主工作台状态；托盘退出能结束进程。

## 后续需细化的设计

- 搜索与流程导航并重的具体布局、完整窗口与悬浮窗口尺寸，以及管理员和业务员各自页面。
- Excel 字段映射、重复导入标识、多语言缺失提示及导入错误处理。
- 个人流程与官方流程的结构冲突、删除处理及版本差异展示。
- 工作组发现失败时的连接入口、管理员电脑更换与备份恢复流程。
- 支持的 Excel、图片和视频具体格式，以及目标 Windows 平台的预览能力。
- 个人分支的备份方式、备份保留数量、同步空间回收与离线电脑补更新规则。

## 不在首版范围

独立公网服务端、在线账号登录与授权、多个管理员资料库切换、业务员之间相互转发同步、自动翻译、图片 OCR、自动向 LDCLOUD 上传文件、客户管理与按客户保存进度。
