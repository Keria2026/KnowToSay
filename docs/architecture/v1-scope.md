# 第一版范围与验收场景

## 目标与状态

为多语言销售提供可离线运行的 Windows 10+ Tauri 桌面客户端，用于沿沟通流程选择话术、填写变量、复制回复，以及查找和导出知识库素材。

本文记录已确认范围。仓库已有开发版本及自动测试；实现与目标平台验证边界见[开发指南](../getting-started/development.md)。

## 工作组与角色

- 一个局域网按一个工作组使用，只有一个管理员提供资料同步。每名业务员只属于一个管理员。
- 通过首次明确选择“创建工作组”并完成初始化建立管理员身份，不以安装时间戳或一次网络探测失败来选举管理员。
- 后续电脑加入已有工作组成为业务员。首次加入需要管理员在线；已经加入的电脑可继续离线使用。
- 管理员身份持久保存，不因客户端退出或网络不可达自动转移。新电脑找不到管理员时，不自动成为新管理员。
- 首版不登录、不做在线授权。管理模式和业务员模式划分操作职责，不宣称提供已认证的账号权限或资料防复制保护。

## 话术与流程

- 预估约 2,000 条话术。支持题目、问题、多个语言版本的回复。
- 支持独立命名的多条流程，可新建、重命名，并在编辑画布和销售工作台上方用标签切换。标签支持拖动排序，也可打开“流程排序”使用前后移动按钮；聚焦标签后可用 Alt + 左右方向键调整。顺序按工作组保存在本机，工作台、编辑器和悬浮窗共用；新流程追加到末尾，已保存的显示顺序不随管理员同步覆盖。流程话术归属于具体流程，不设分类；快捷话术分类与知识库分类保留。空流程也随发布、同步、资料包与备份保留。
- 快捷话术支持独立新建分类，空分类也能保存。管理员分类随发布、同步、资料包和备份恢复保留；业务员可建立个人分类，个人备份包含空分类。原有快捷话术分类自动保留，未指定分类的归为“未分类”；流程话术不参与快捷分类。销售工作台与话术与流程复用同一套“话术类型 → 流程或分类标签”导航，位置、选中样式和切换交互一致，悬浮窗也可切换。分类排序沿用流程的拖动、键盘和排序弹窗，按工作组保存在本机；切换类型或标签不丢失编辑草稿，新话术默认归入当前分类。
- 话术类型由创建入口确定，编辑器不提供类型切换；空流程中创建的首个节点自动作为入口，后续新建节点不是入口，不显示入口复选框。已有资料的入口标记保留。
- 管理员可重命名或删除快捷分类，业务员可管理自己的个人分类，官方分类由管理员统一维护；内置“未分类”不可改名或删除。删除分类将其中话术移入未分类，保留回复和未保存编辑。
- 明确区分“流程话术”和“快捷话术”。流程话术通过分支组织沟通步骤；快捷话术针对客户特定问题或回复提供独立的一对一回答，无需进入流程。
- 管理员人工录入各语言版本；支持从现有 Excel 话术表批量导入。
- 支持分支、汇合、跳转及共同话术复用；使用时可沿流程选择、返回和复制。
- 流程编辑支持拖动节点保存排版、自动排列、从连接点拉箭头到已有节点新增分支；拉到画布空白处可创建子话术并填写分支条件。点击连线可以修改条件或删除分支。
- 自动排列按照真实连接、分支顺序和子树所需空间排列，汇合步骤位于全部上游之后；回跳仍保留为返回箭头。分支条件显示在来源步骤内，各自使用独立连接点，避免不同分支共用线段与居中标签造成归属误读。只有明确点击自动排列才改写已有手动坐标，且只作用于当前流程。
- 编辑器使用中文、韩语等可读名称，不要求输入语言代码；现有额外语言内容继续保留。
- 图表和右侧内容编辑共享待保存修改，切换节点或流程标签不会丢失编辑；点击“保存流程”或“保存话术”时将全部修改作为同一事务保存。失败保留待保存内容，离开编辑页时提示放弃全部修改。
- 快捷话术不设置流程入口或分支，也不作为流程跳转目标；两类话术均支持语言、变量、素材引用、全局搜索与个人编辑。现有话术保留为流程类型，不按有无分支自动分类。
- 话术支持客户姓名、产品名、价格等变量，复制前填写、预览；必填变量缺失时提示。
- 话术步骤可以引用知识库中的图片、视频、表格等素材。
- 不建立客户档案，不按客户保存流程进度。

## 业务员个人分支

- 业务员可以修改题目、问题、多语言回复、变量，新增个人话术并调整流程连接与分支。
- 个人修改只保存在本地，不回传管理员，不影响其他业务员。
- 管理员发布版本持续同步。业务员修改过的内容保持个人版本，未修改内容跟随管理员更新；最新管理员版本仍可供查看。
- 默认使用个人版本，支持明确放弃个人修改并恢复管理员版本。此操作不能作为同步时的隐式行为。
- 话术、流程及引用需要稳定标识，不能按标题、列表位置或 Excel 行号猜测同一项内容。
- 同步不得整体覆盖业务员数据库，亦不得静默丢弃个人新增话术或流程连接。
- 知识库由管理员统一管理，业务员可引用和使用，不能将知识库修改作为个人分支回传或发布。

个人版本按完整话术覆盖同 ID 的管理员版本，不做逐字段自动合并。个人修改依赖的管理员步骤与流程会保留；管理员删除后，仍被个人分支依赖的步骤以“保留的话术”继续使用，未修改且无个人依赖的内容跟随发布。恢复管理员版本为显式操作，并清理不再需要的依赖。当前没有可视化冲突合并器。

## 知识库与搜索

- 预估素材总量 20–30GB，支持文字、图片、视频和 Excel。
- 支持分类、标签、备注、查找和预览。管理员可独立新建分类，无素材的空分类也会持久保存；分类属于主库草稿，随发布、同步、资料包和管理员备份恢复一起处理。业务员只能使用已发布分类。
- 知识库可按分类筛选；素材编辑支持选择已有分类。选中分类后创建文字或导入文件，默认归入该分类；全部分类视图下导入文件归为“未分类”。分类重名与空名称会提示，名称最多 80 个字符。
- 可搜索标题、分类、标签、备注、文字正文及 Excel 单元格；Excel 结果能定位到工作表和行。
- 第一版不做图片 OCR 或视频语音转写。
- 素材文件按需读取和预览，不要求将全库载入内存。
- 导入的素材在本地保存，源 Excel 或源素材移走后不能导致已入库资料失效。
- 管理员删除素材并发布后，业务员成功同步该版本时移除素材的可用入口。引用它的个人话术保留，关联处提示“素材已移除”，允许重新选择素材；不因个人引用继续提供旧素材。
- 管理员草稿中的删除不提前影响业务员；离线电脑在成功同步之前继续使用当前已安装版本。更新失败不能提前应用删除。历史回滚或备份中的文件不作为当前素材对业务员开放。

## 发布、同步与恢复

- 管理员编辑期间为草稿，明确点击发布后才向业务员提供更新。
- 管理员客户端运行时提供同步；业务员自动获取已发布更新，断线后重新连接时补齐。
- 首次全量获取，后续增量同步；大文件传输支持断点续传。
- 同步期间原版本继续可用。新版本需要完整性检查和空间检查，更新失败保留旧版本，不能形成半新半旧的可用发布版本。
- 素材与引用需一起达到可用状态，不能先切换到引用尚未传完素材的新版本。
- 个人话术分支不因更新、重试、断网、重启而丢失。
- 管理员具备备份和恢复功能，备份覆盖资料、素材及恢复工作组所必需的状态。
- 保留资料包导入导出，作为备用分发方式；仍需遵循同样的完整性与个人修改保护要求。
- 管理员可在设置中将其他工作组备份的草稿资料导入为自己的数据，追加到当前主库而不替换已有内容。导入保持当前工作组身份和已发布版本，为导入内容重新分配标识并保留连接、素材引用和排版；同名流程自动区分，导入内容检查后发布。原工作组的备份恢复仍单独提供。

## 实际发送链路

业务员在 Windows 客户端选择文字或素材。文字复制后在实际 LDCLOUD / KakaoTalk 环境粘贴；素材通过打开所在位置或导出选中文件，手动上传到 LDCLOUD 云机，再在云机内的 KakaoTalk 选择发送。

不将桌面文件复制等同于已向云机传输；文本剪贴板能否跨云机使用需要实际验证。首版不自动上传云机，不自动向客户发送消息。

## 工作台与窗口

- 业务员同时频繁使用全局搜索和流程导航，两个入口均为主操作，不将其中一个藏入管理页面。
- 全局搜索覆盖话术、知识库素材和 Excel 内容。流程导航提供当前步骤、可选分支、返回及关联素材。
- 搜索到的话术同时显示中文与韩语回复，独立搜索栏也使用双语展示；缺失某一语言时明确提示。复制仍只使用选定发送语言，并遵循变量校验。
- 销售工作台可切换流程标签并展开当前完整流程图，展示所选流程的全部步骤（包括未连接步骤）、分支、汇合和跳转，高亮当前话术。内嵌图点击节点会切换当前话术，支持平移、缩放与适应画布；工作台图表用于查看，编辑在“话术与流程”中完成。
- 工作台与编辑页均支持全屏查看当前流程，右侧悬浮竖向详情栏展示节点问题、中韩回复、变量、复制预览、下一步和素材名称。全屏点击节点仅改变查看选择；明确选择继续工作台或返回编辑后才定位原页面。退出按钮、Esc 或 F11 返回原窗口，保留工作台步骤和未保存编辑。
- 完整窗口提供销售工作台、话术与流程、知识库和设置。置顶悬浮窗仅用于销售取用，提供流程、快捷话术、知识库三项，只查看、填写必要变量、复制或导出；不提供新建、编辑、发布和备份。
- 悬浮窗保留当前步骤与变量，切换回完整窗口保留原编辑页面及所有未保存草稿，并恢复原窗口大小和位置。组件按窗口宽高重排，窄屏只在必要容器内滚动。
- 搜索默认全局，可按流程、快捷话术或知识库缩小范围，并进一步限定流程或分类；结果卡片直接复制，详情按需打开，必填变量缺失时先填写预览。
- 表格按行列预览，支持工作表切换、列名、原行号、分页、横向滚动、单元格复制和整行复制；新上传表格保留非 A 列起点。
- 悬浮窗口不扩展为 KakaoTalk 自动发送或云机文件自动传输工具。
- Windows 最小化或关闭工作台后常驻托盘，明确选择托盘“退出”才退出程序。通过托盘可以打开工作台或独立搜索栏。
- 全局快捷键与屏幕边缘唤出同一个独立搜索栏。默认 Ctrl+Alt+Space，可修改或关闭，唤出时范围为全局；边缘唤出时范围为快捷话术，无关键词也直接列出回复。窗口内只通过统一范围选择器切换全局、流程话术、快捷话术或知识库，不增加独立的“全库搜索”或“回复表”模式。Esc 或再次按快捷键收起，复制成功后默认收起，保留主工作台当前流程。
- 默认右边缘停留 400ms 触发；上下左右四边可分别配置，停留时间可设置为 200–2000ms。边缘触发仅在主工作台已收起时启用，拖拽或其他全屏应用中暂停。
- 独立搜索栏可以搜索话术、素材和 Excel 单元格，填写必要变量并复制；也可明确打开主工作台中的对应话术。业务员个人版本优先。
- 独立搜索栏的快捷话术范围支持分类与关键词筛选、切换发送语言和直接复制；存在未填写变量时先打开填写与预览，缺失语言时不复制替代语言。

## 技术与设计约束

采用 [已批准的桌面存储决策](../adr/0001-offline-desktop-storage.md)。工程规范见 [AGENTS](../../AGENTS.md)，视觉设计见 [DESIGN](../../DESIGN.md)。

视觉遵循单一蓝色强调色、统一排版与留白。完整窗口使用侧栏四页导航与顶部搜索工具栏，悬浮窗使用只读流程、快捷话术和知识库导航；不显示独立黑色品牌条或侧栏工作组卡片。当前导航浅蓝高亮、文字 600 加强，未选中项浅灰。应用内、桌面与安装器使用同一版 Logo；Windows 升级时刷新已有快捷方式。桌面适配以[页面与操作流程](desktop-interactions.md)为准，不照搬营销页布局。

## 必需验收场景

以下为必需验收目标。当前自动覆盖和仍待人工验证的场景见开发指南，不将全部目标视为已在真实 Windows 环境执行。

1. 两台电脑建立工作组，业务员同步已发布资料；管理员退出后，业务员仍可搜索、导航、填写变量并复制回复。
2. 管理员修改草稿，业务员看不到；发布后自动更新，未修改的官方话术及流程可以正常使用。
3. 业务员修改个人话术、新增步骤和连接；管理员更新相关官方内容后，个人内容和连接仍保留，且能够查看最新官方版本。
4. 中断大文件传输并重启客户端后续传；文件不重复写坏，空间不足或校验失败时不切换当前发布版本。
5. 搜索指定 Excel 单元格中的内容，结果对应正确工作表和行；原文件可定位和导出。
6. 管理员创建一致备份并在测试数据目录恢复，能重新识别工作组、读取话术流程及完整素材；恢复操作不能误生成第二个管理员。
7. 在真实 Windows、LDCLOUD 和 KakaoTalk 环境验证文本粘贴、素材导出及人工上传发送链路。
8. 在完整窗口和置顶悬浮窗口之间切换，搜索和流程均可使用；临时步骤与变量保持一致，切换不会重复创建或覆盖个人话术。
9. 管理员删除被个人话术引用的素材并发布；成功同步后素材不再可用，个人话术及流程保持，引用处明确提示失效；同步失败或草稿删除不提前移除当前可用素材。
10. Windows 最小化到托盘后，屏幕边缘和全局快捷键唤出同一搜索栏，分别默认选择快捷话术与全局范围；Esc 收起，复制和打开话术不丢失主工作台状态；托盘退出能结束进程。
11. 工作台和编辑页全屏查看当前流程，包含未连接步骤；右侧显示点击节点的详情，退出保留工作台步骤、窗口状态与未保存编辑。
12. 升级 Windows 安装包后，桌面快捷方式、开始菜单、原生窗口与应用内品牌显示同版 Logo；四页导航选中状态清楚，窄窗仍可访问。

## 实现与验收边界

多流程、快捷分类、Excel 字段映射、个人备份、同组恢复、跨工作组备份导入和全屏查看均已有实现，不再作为待设计事项。具体使用与数据边界见[页面与操作流程](desktop-interactions.md)和[开发指南](../getting-started/development.md)。

尚未实现的能力包括逐字段冲突合并、自动清理历史素材及旧版本文件、自动备份保留轮换。目标平台仍需验证实际媒体编解码器、Windows 安装升级与图标缓存、原生窗口全屏、多屏/快捷键，以及大容量真实局域网传输；不得将浏览器自动检查当作这些场景的通过记录。

## 不在首版范围

独立公网服务端、在线账号登录与授权、多个管理员资料库切换、业务员之间相互转发同步、自动翻译、图片 OCR、自动向 LDCLOUD 上传文件、客户管理与按客户保存进度。
